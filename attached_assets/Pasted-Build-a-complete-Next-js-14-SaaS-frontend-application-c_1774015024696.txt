Build a complete Next.js 14 SaaS frontend application called "FASHLINK" — an AI creative direction platform exclusively for fashion stylists. All UI text in French. No mock data, no simulations.

## TECH STACK
- Next.js 14 (App Router, TypeScript)
- Tailwind CSS (no component library)
- Framer Motion for animations
- NextAuth.js (credentials provider)
- Prisma + PostgreSQL
- Anthropic Claude API (claude-sonnet-4-20250514)
- OpenAI API (DALL·E 3 + GPT-4 Vision) for sketch-to-illustration
- jsPDF for certificate export
- next/font for Google Fonts

## DESIGN SYSTEM — NON-NEGOTIABLE
- Primary background: #FFFFFF
- Primary text: #000000
- Accent: #000000
- Zero border-radius everywhere (border-radius: 0 on ALL elements)
- Zero box-shadows
- Zero color gradients
- Headings font: "Unbounded" via next/font/google
- Body font: "Montserrat" weight 600 via next/font/google
- Buttons: black background, white text, sharp corners, uppercase tracking-widest
- Cards: white bg, 1px solid black border
- Inputs: 1px solid black border, no radius, black focus ring
- Dividers: 1px solid black lines
- Layout: editorial minimalism, generous whitespace, asymmetric grids
- Animations: subtle fade-in on page load (Framer Motion), staggered list reveals, hover underline slide on nav links
- Custom CSS cursor: crosshair

Apply fonts globally in layout.tsx using CSS variables --font-heading and --font-body.

### TAB 3 — ILLUSTRATION (CROQUIS → 2D)

SketchUploader component:
- Large dashed black border upload zone (no radius)
- Text: "DÉPOSEZ VOTRE CROQUIS ICI" in Unbounded
- Sub: "JPG, PNG — 5MB max"
- On file select: show preview image in black border frame
Optional input: "Précisions stylistiques" (ex: robe longue, style épuré, noir)
Button "TRANSFORMER EN ILLUSTRATION 2D"

On submit: POST /api/projects/[id]/generate-illustration
API route:
1. Receive base64 image + style text + user ADN synthese
2. Call GPT-4 Vision: "Décris précisément ce croquis de mode en français pour générer une illustration 2D professionnelle. Inclus: type de vêtement, silhouette, détails vestimentaires, style."
3. Build DALL·E 3 prompt: "Professional 2D fashion illustration, flat design, technical fashion sketch style, clean lines, white background, black outlines, {GPT-4 description}, {user style precision}, {user ADN dominant style}. NOT photorealistic. Illustration only."
4. Call DALL·E 3, return image URL
5. Save to DB (illustrations table)

IllustrationResult component:
- Side-by-side: sketch (left) | illustration (right), both in black border frames
- Labels "CROQUIS ORIGINAL" and "ILLUSTRATION GÉNÉRÉE" in Unbounded small
- Button "TÉLÉCHARGER L'ILLUSTRATION" (downloads image)
- Button "AJOUTER AU CERTIFICAT" (toggles flag in DB)

## DATABASE SCHEMA (Prisma)

model User {
  id String @id @default(cuid())
  email String @unique
  password String
  name String
  adn_inspirations String?
  adn_valeurs String[]
  adn_marche String?
  adn_prix String?
  adn_style String?
  adn_synthese String?
  projects Project[]
  createdAt DateTime @default(now())
}

model Project {
  id String @id @default(cuid())
  userId String
  user User @relation(fields: [userId], references: [id])
  title String
  theme String?
  season String?
  shareToken String? @unique
  generations AiGeneration[]
  illustrations Illustration[]
  materials Material[]
  createdAt DateTime @default(now())
}

model AiGeneration {
  id String @id @default(cuid())
  projectId String
  project Project @relation(fields: [projectId], references: [id])
  type String
  content Json
  createdAt DateTime @default(now())
}

model Illustration {
  id String @id @default(cuid())
  projectId String
  project Project @relation(fields: [projectId], references: [id])
  sketchUrl String
  resultUrl String
  inCertificate Boolean @default(false)
  createdAt DateTime @default(now())
}

model Material {
  id String @id @default(cuid())
  projectId String
  project Project @relation(fields: [projectId], references: [id])
  content Json
  createdAt DateTime @default(now())
}

## IMPORTANT RULES
- All UI text strictly in French
- No mock data anywhere — all AI calls are real API calls
- All dashboard routes protected server-side (redirect to /auth/signin if no session)
- Framer Motion page transitions: fade + slight translateY on every page
- Mobile responsive: sidebar collapses to hamburger menu on mobile
- Error states: if API call fails, show black error card with message
- Loading states: always show Spinner + contextual text during AI generation
- jsPDF for all PDF exports (client-side, no server PDF)
- Images uploaded for sketch are converted to base64 client-side before sending to API
- RLS equivalent: all DB queries filtered by session userId
