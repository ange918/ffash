Crée une application Next.js 14 avec App Router, TypeScript et Tailwind CSS.
Il s'agit du site e-commerce de "Cosmetics Shop", une boutique de
cosmétiques spécialisée dans les soins corporels et visage au Bénin.

── STACK ──
Next.js 14 App Router
TypeScript
Tailwind CSS (config étendue)
Framer Motion (animations, directive "use client")
Zustand (état global panier, persist middleware localStorage)
Google Fonts via next/font/google :
  - Unbounded (weights 300, 400, 600) → titres
  - Montserrat (weights 400, 500, 600) → textes
Applique les fonts dans app/layout.tsx via className sur <body>

── DONNÉES PRODUITS ──
Crée lib/products.ts avec un tableau TypeScript de TOUS les produits suivants.
Type Product :
  id: number
  nom: string
  categorie: string   // ex: "Savons Corporels"
  gamme?: string      // ex: "Molato", "Nila", "Collagène", "Rondeurs"
  typePeau: string[]  // ex: ["grasse", "sèche", "mixte", "sensible", "tous"]
  description: string // courte, générée de façon cohérente
  prix: number        // prix fictif réaliste en FCFA (500–8000)
  badge?: string      // ex: "Nouveau", "Bestseller", "Spécial Homme", "Bébé"
  image: string       // chemin "/images/placeholder.jpg" pour tous

── RÈGLES TECHNIQUES ──
- Toutes les pages/composants interactifs → "use client"
- Images : utiliser Next.js <Image> avec width/height explicites
  ou unoptimized pour les placeholders
- Pas de bibliothèque UI externe (pas Shadcn, MUI, etc.)
- next.config.ts : pas de config spéciale requise
- Vercel-ready : aucune dépendance serveur, pas d'API route requise
- Le numéro WhatsApp "+22900000000" doit être défini dans
  une constante lib/constants.ts facilement modifiable
